# Regulation & value landscape — what CarbonKeel builds next

Scan date 8 Jul 2026. Each item: what it is, who feels the pain, the product
angle, and a build priority (P1 = next tabs, P2 = pipeline, P3 = watch).
Current coverage: CII, EEXI (free), EU ETS, UK ETS, FuelEU (+pooling), IMO
NZF scenario, compliance calendar.

## P1 — build as tabs next (clear buyer, data we already have)

**1. Poseidon Principles / ship-finance climate alignment.**
35+ banks (most ship lenders) score every financed vessel's AER against
decarbonisation trajectories and reprice or decline accordingly. Owners get
an annual "alignment delta" letter and often don't understand it. Product:
"Finance readiness" tab — vessel AER vs the Poseidon minimum + striving
trajectories, portfolio-style chart, "what your lender sees" framing. Inputs
= the same CII data we already compute. VERIFY: trajectory tables from the
Poseidon Principles Technical Guidance (public).

**2. Sea Cargo Charter / charterer scrutiny.**
Cargo giants (Cargill, Trafigura…) score chartered tonnage the same way.
A D/E-rated ship increasingly loses charters, not just pays penalties.
Product: same engine as (1), charterer-facing wording; feeds the vetting
answer "will this ship pass a cargo-owner climate screen?"

**3. ETS/FuelEU commercial allocation (who pays?).**
The BIMCO ETSA and FuelEU clauses split allowance/penalty liability between
owner and charterer per voyage. Disputes are live and CFO-relevant. Product:
per-voyage cost-allocation calculator — time-charter vs voyage-charter view,
EUA/penalty split preview, clause-ready numbers. Uses existing per-leg
scoping; needs charter-period input.

**4. SEEMP Part III generator.**
Every D (3-yr) / E ship must file a corrective action plan before its next
SoC. We already output the levers (speed, hull, biofuel, pooling). Product:
pre-filled SEEMP III draft from the vessel's actual numbers — the paid
follow-on to a bad free CII check.

## P2 — pipeline (needs partner data or more build)

**5. FuelEU OPS obligation.** Container/pax ships must use shore power at
berth in TEN-T ports from 2030 (or pay). Product: port-call OPS exposure
screen once we ingest port-call data (AIS or noon reports).

**6. Med/North Sea ECAs & fuel switching.** Med SOx ECA live since May 2025;
NOx/PM tightening. Not GHG but same fuel data; cheap adjacency for the
what-if simulator (fuel-cost + compliance joint view).

**7. CSRD / Scope 3 for cargo owners.** EU corporates must report logistics
emissions (GLEC/ISO 14083). Product: shipper-grade emissions statements per
cargo/voyage from the same engines — a second customer segment (cargo
owners), sell the SAME data twice.

**8. EU ETS 2026 review.** Possible extension to 400–5,000 GT ships and
offshore vessels (≥5k GT offshore joins 2027). Watch; engines already
parameterised by GT threshold.

**9. Carbon-credit adjacencies.** Shipping's "credits" are compliance
instruments, not voluntary offsets: FuelEU surplus (tradable via pooling —
LIVE), coming NZF Surplus Units (Phase 3 marketplace), and EUA hedging
strategy (price sensitivity now in UI; hedging calendar = CFO feature).
Voluntary offsets deliberately out of scope — reputational minefield,
no regulatory recognition in any of the four regimes.

## P3 — watch list
- IMO NZF adoption vote ~Oct 2026 (pre-drafted announcements ready).
- UK ETS international-voyage consultation.
- CII Phase 2 review (2026–28): possible metric change (EEOI/cbDIST) —
  engines stay table-driven for this reason.
- FuelEU RFNBO 2% mandate trigger (2034, monitored from 2031).
- IMO onboard carbon capture (OCC) crediting rules — would change every
  engine's CO₂ math; MEPC working group ongoing.
